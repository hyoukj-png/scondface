# �️ 카테고리 관리 시스템 가이드

## 📌 개요

관리자 페이지에서 상품 카테고리를 동적으로 관리하는 시스템입니다.
DB에 저장된 카테고리는 **상품 등록** 시 선택 옵션과 **쇼핑몰 페이지**의 필터로 자동 반영됩니다.

---

## � 관리자 페이지 사용법

**주소**: `http://localhost:3000/admin/categories`

### 1️⃣ 목록 조회 및 정렬

- 등록된 모든 카테고리가 목록에 표시됩니다.
- **정렬 순서(Sort Order)** 번호가 낮은 순서대로 쇼핑몰 필터와 드롭다운에 표시됩니다.

### 2️⃣ 카테고리 추가

1. **"새 카테고리"** 버튼 클릭
2. 입력 필드:
   - **카테고리 값 (영문)**: URL이나 데이터 매핑에 사용 (예: `sunglasses`) -> *자동으로 소문자 변환 & 공백 제거*
   - **카테고리 이름**: 화면에 표시될 이름 (예: `선글라스`)
   - **정렬 순서**: 표시 순서 (숫자)
3. **"추가하기"** 버튼 클릭

### 3️⃣ 수정 (인라인 편집)

목록에서 바로 수정할 수 있습니다.

- **연필 아이콘 (✏️)** 클릭 시 편집 모드 활성화 (또는 값을 직접 클릭)
- **수정 가능 항목**:
  - `순서`
  - `카테고리 값`
  - `카테고리 이름`
- **저장**: 입력 후 **Enter** 키 또는 밖을 클릭
- **취소**: **ESC** 키

### 4️⃣ 삭제

- **휴지통 아이콘 (🗑️)** 클릭
- 실제 DB에서 삭제되지 않고 `is_active = false` 상태로 변경되어 화면에서만 숨겨집니다. (데이터 무결성 보호)

---

## �️ 기술적 변경사항

### ✅ 데이터베이스 (Supabase)

- **테이블**: `categories`
- **필드**:
  - `id`: UUID (Primary Key)
  - `value`: text (unique)
  - `label`: text
  - `sort_order`: numeric (default: 999)
  - `is_active`: boolean (default: true)
  - `created_at`: timestamptz

### ✅ API 엔드포인트

`/api/categories`

- **GET**: 활성화된(`is_active=true`) 카테고리 목록 조회 (정렬 순)
- **POST**: 새 카테고리 추가
- **PUT**: 카테고리 정보 수정 (순서, 이름, 값 등)
- **DELETE**: 카테고리 비활성화 (Soft Delete)

---

## � 관리자 참고사항

1. **영문 이름(label_en) 제거**: 불필요한 필드를 제거하고 UI를 간소화했습니다.
2. **카테고리 값(value) 주의**: 이 값은 상품 데이터와 연결되므로, 이미 상품이 등록된 카테고리의 `value`를 변경하면 해당 상품들이 검색되지 않을 수 있습니다.
3. **반영 시간**: 추가/수정 후 페이지를 새로고침하면 즉시 반영됩니다.
